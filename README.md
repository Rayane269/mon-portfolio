# 🚀 Portfolio Professionnel - Administrateur Système, Réseau & Sécurité

Bienvenue sur le dépôt de mon portfolio. Ce projet est une vitrine de mes compétences techniques en infrastructure IT, cybersécurité et gestion de services, développée avec des technologies modernes de développement web.



## 👤 À propos
Je suis **SOULAIMAN Rayane**, futur Administrateur Système et Réseau. Ce portfolio me permet de partager mes documentations techniques et de démontrer ma capacité à déployer des solutions complexes, sécurisées et performantes.

## 🛠 Stack Technique
* **Framework :** [Next.js](https://nextjs.org/) (React)
* **Design :** [Tailwind CSS](https://tailwindcss.com/)
* **Gestion de contenu :** Markdown & MDX
* **Déploiement :** [Vercel](https://vercel.com/)
* **Outils :** Git, GitHub, Lucide Icons

## 📂 Projets & Réalisations Techniques
Chaque projet sur le portfolio inclut un rapport technique complet au format PDF.

### 🔐 Cybersécurité : Analyse ARP & Spoofing
* Simulation d'attaques de type **Man-in-the-Middle (MITM)**.
* Analyse de trames réseau avec **Wireshark**.
* Utilisation de **Scapy** (Python) pour forger des paquets et comprendre l'empoisonnement du cache ARP.

### 🏢 Infrastructure : Active Directory (Windows Server 2025)
* Installation et promotion de contrôleurs de domaine.
* Conception de structures d'Unités d'Organisation (OU).
* Mise en place de **GPO** (Group Policy Objects) pour la gestion centralisée de la sécurité et des postes clients.

### 🛠 Gestion IT : GLPI & ITSM
* Déploiement d'une solution **GLPI** sur une pile LAMP (Linux).
* Inventaire automatique des actifs via des agents.
* Mise en place d'un centre de services (**Helpdesk**) et interconnexion **LDAP/Active Directory**.

## 🚀 Installation Locale

Si vous souhaitez explorer le code ou lancer le projet sur votre machine :

1.  **Cloner le projet :**
    ```bash
    git clone https://github.com/Rayane269/mon-portfolio
    ```
2.  **Installer les dépendances :**
    ```bash
    npm install
    ```
3.  **Lancer le mode développement :**
    ```bash
    npm run dev
    ```
    Accédez ensuite à `http://localhost:3000`.
